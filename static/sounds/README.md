# SFX Sound Library

Place your audio files in this directory.

## Supported Formats
- MP3
- WAV
- OGG
- M4A (AAC)

## Tips for Good SFX Files

- **Length:** 1-3 seconds for short effects, 5-30 seconds for ambience
- **Format:** MP3 at 128-192 kbps for smaller size
- **Normalization:** ~ -6dB to -3dB peak for consistent volume
- **Fade:** Add short fade-in/out (10-50ms) to avoid clicks
- **Loop points:** For drones/ambience, seamless loop is ideal
