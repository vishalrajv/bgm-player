🎭 How to Use

Basic Usage

  • Press any keyboard key to trigger its associated sound effect
  • Multiple keys can be pressed simultaneously for layered SFX
  • Each key is mapped to an emotional category (Tension, Suspense, Happy, Comedy, Sad, Neutral)

Customizing Key Bindings

  • Click any key on the virtual keyboard to remap it
  • A prompt will appear — press the new key you want to assign
  • Press Escape to cancel rebinding
  • Click "Reset Bindings" to restore defaults

Adding Your Own SFX Files

  • Open the static/sounds/ folder
  • Add MP3, WAV, OGG, or M4A audio files
  • Name them according to the sound labels (e.g., cheer.mp3, tension_drone.wav)
  • Refresh the page — new sounds will automatically appear

UI Colors

Each emotional category has a unique neon color for quick recognition:

Tension - Red Suspense - Purple Happy - Yellow Comedy - Pink Sad - Cyan Neutral - Green
